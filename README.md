# Primeros pasos con GitHub Copilot

_Comienza a usar GitHub Copilot en menos de una hora._

## Te damos la bienvenida

- **Para quién es**: Desarrolladores de cualquier nivel de experiencia que quieran acelerar su flujo de trabajo de programación.
- **Qué aprenderás**: Las distintas formas de interactuar con Copilot para explicar, escribir, planificar y desarrollar código.
- **Qué crearás**: Guiarás a Copilot para actualizar el sitio web de actividades extracurriculares de Mergington High School.
- **Requisitos previos**:
  - Ejercicio práctico: [Introducción a GitHub](https://github.com/skills/introduction-to-github)
  - Familiaridad con [VS Code](https://code.visualstudio.com/)
  - Principios básicos de programación
- **Duración**: Este ejercicio toma menos de una hora completarlo.

En este ejercicio:

1. Usarás un Codespace preconfigurado para ejecutar VS Code en tu navegador.
1. Conocerás diferentes opciones de interacción para desarrollar y planificar con GitHub Copilot.
1. Usarás Copilot para resumir y revisar tu solicitud de incorporación de cambios.

### Cómo comenzar este ejercicio

Simplemente copia el ejercicio en tu cuenta y dale a tu Octocat favorito (Mona) **unos 20 segundos** para preparar la primera lección. Luego, **actualiza la página**.
